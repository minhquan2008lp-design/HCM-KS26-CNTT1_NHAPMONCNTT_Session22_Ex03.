# INPUT
Câu trả lời từ AI chứa hướng dẫn sửa lỗi "Path not found" khi cài đặt Python.

Một câu lệnh lạ, dạng gạch đầu dòng, yêu cầu dán vào Terminal/Command Prompt có khả năng can thiệp sâu vào hệ thống.

# Process
Bước 1: Trích xuất đoạn mã nghi vấn. Tách riêng câu lệnh AI cung cấp.

Bước 2: Tìm kiếm nâng cao để đối chiếu dữ liệu
 Sử dụng công cụ tìm kiếm với các cú pháp chuẩn hóa để tra cứu tài liệu chính thống hoặc cộng đồng uy tín:

 site:stackoverflow.com "đoạn_lệnh_AI_đưa_ra"

 site:docs.python.org "tên_hàm_hoặc_biến_trong_lệnh"

 Bước 3: Phân tích cú pháp 

 Bóc tách các từ khóa trong lệnh để xem nó thực sự tác động đến thư mục nào Đối chiếu xem có dấu hiệu AI Hallucination hay khoong
